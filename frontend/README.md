# FallGuard Frontend

Privacy-first fall detection caregiver dashboard.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy environment variables:
   ```bash
   cp .env.example .env.local
   ```
   Set `NEXT_PUBLIC_DEV_AUTH_BYPASS=true` for local development without a backend.

3. Run the development server:
   ```bash
   npm run dev
   ```
